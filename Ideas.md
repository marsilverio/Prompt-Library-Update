[06-10-2026 20:08] | Android companion app: AirDrop style sharing (supersedes the QR pairing plan above) | No pairing. Every running Prompt Library (desktop or phone) listens on one fixed sharing port and answers a hello with its device ID, name and type. Tap Send on a prompt, the app scans the local network (about 254 addresses, a few seconds) and shows found libraries as AirDrop style device icons. Tap one, the receiver shows "Eugene's Phone wants to send 'Prompt title'. Decline / Accept". Accept saves it to a "Received" folder, sender sees Sent or Declined. Works phone to desktop, desktop to phone and desktop to desktop. Phone receives only while the app is open on screen (Android limit, same as AirDrop needing the screen awake), so no outbox. Sharing port exposes only hello, send request and accept or decline, never the full /api. Received prompts use the existing prompts table and device ID uses the existing settings table, so likely no schema change (verify against init_db() first). Subnet scan replaces zeroconf, so no new dependency; Android NSD discovery can be added later. Order: v0.1 APK (library, search, viewer, copy, create, JSON import from /api/export), v0.2 phone to desktop send, v0.3 desktop to phone and laptop to laptop, later "Always accept" trusted devices, Android share target, mDNS.
